# Terraform Associate 004 Study Website

Terraform Associate 004와 Terraform 1.12 학습을 위한 한영 병기 정적 웹 사이트입니다. 기존 학습 자료는 `src/content/docs/archive/`로 마이그레이션되었으며, 사이트의 핵심 경로는 공식 시험 목표 1a-8d 순서로 구성됩니다.

This is a bilingual static study website for Terraform Associate 004 and Terraform 1.12. Migrated material lives under `src/content/docs/archive/`, while the core path follows official objectives 1a-8d.

## Run locally

```bash
npm install
npm run dev
```

Production search is generated by Pagefind during the static build.

```bash
npm run build
npm run preview
```

The production output is written to `dist/`. Set `SITE_URL` to the canonical deployment origin before building.

```bash
SITE_URL="https://terraform-study.example.com" npm run build
```

## Content structure

- `src/content/docs/domains/`: bilingual Domain 1-8 curriculum
- `src/content/docs/guide/`: learning path, labs, and practice workflow
- `src/content/docs/reference/`: objectives, glossary, corrections, source map, and authoring rules
- `src/content/docs/archive/`: migrated legacy study material
- `src/content/docs/practice/`: original practice questions derived from objective coverage research
- `public/lab-files/`: reviewed downloadable Lab 01-03 solutions
- `public/practice-files/`: reviewed hello-world configuration artifacts

## Refresh official sources

```bash
npm run sources:update
```

This command resolves curated Terraform 1.12 paths from `hashicorp/web-unified-docs` and writes immutable source metadata to `src/data/official-source-index.json`. Review the upstream BUSL 1.1 license before redistributing original HashiCorp content.

## Editorial policy

- Official HashiCorp objectives and versioned Terraform 1.12 documentation are primary.
- Public practice and dump sites may inform topic coverage only.
- Leaked or memorized live-exam questions are not copied.
- New questions must be original, scenario-based, bilingual, and cite the concept source used to explain the answer.
